# Skills seleccionadas

Instalación local al proyecto el 10/10/2026. Disponibles automáticamente en Codex desde el siguiente turno; `AGENTS.md` también indica cuándo leerlas. Se conservan en GitHub para que otro integrante use el mismo criterio.

| Skill | Origen | Uso |
| --- | --- | --- |
| frontend-design | [anthropics/skills](https://github.com/anthropics/skills/tree/main/skills/frontend-design) | Plan de identidad, jerarquía, composición y revisión visual. Se conserva LICENSE.txt. |
| web-design-guidelines | [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) | Revisión de accesibilidad, interacción, responsive y rendimiento. Consulta sus reglas actuales en el origen indicado por la skill. |
| onconova-storytelling | Elaboración propia | Orden de la actividad, lenguaje cercano, fuentes, simulaciones y límites de los resultados. |

También se revisó [obra/superpowers](https://github.com/obra/superpowers), especialmente investigación de errores y verificación. No se instaló el paquete completo: este sitio estático no requiere incorporar todo su proceso. Codex ya dispone de una skill de debugging en el entorno del usuario.

Las dos skills externas se descargaron mediante Skill Installer desde sus repositorios oficiales. Se revisaron sus instrucciones antes de aplicarlas. No ejecutan servicios, publican datos o conceden accesos por sí mismas. Las preferencias explícitas del equipo prevalecen sobre consejos estéticos generales.

Para pedir una revisión en Codex: «Usa $onconova-storytelling para revisar el relato y las fuentes», «Usa $frontend-design para ajustar esta sección» o «Usa $web-design-guidelines para revisar la interfaz».

No actualizar automáticamente las skills durante una compilación. Revisar los cambios antes de reemplazar la versión incluida en el repositorio.
